# Noventiq OpsAgent — Guided Booth Simulation

## Run locally

Keep `index.html`, `styles.css`, and the `assets` folder together. Open `index.html` in Microsoft Edge or Google Chrome. No server, internet connection, installation, or login is required.

## Presenter controls

- **Start Demo** begins the guided sequence.
- **Pause / Resume** stops and resumes the automatic transition between system steps.
- **Previous / Next** lets the presenter move through frames manually.
- The Sales Review, General Manager Approval, and final Outlook Send stages wait for manual action.
- **Restart Demo** resets the complete scenario.

## Scenario

The simulation represents Grandview Singapore Hotel. All commercial values use Singapore dollars (SGD / S$).

## Package contents

- `index.html` — interface structure, workflow data, and interaction logic
- `styles.css` — primary interface styling
- `assets/refinements.css` — enhanced Microsoft application and presenter-control styling
- `assets/*.svg` — all Noventiq, Microsoft product, PDF, status, presenter, and ballroom visual assets

This is a controlled visual simulation for presentation use. It does not connect to production Microsoft 365 services or transmit customer data.
